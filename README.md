# Marketing Campaign Performance Dashboard

An interactive **Marketing Campaign Performance Dashboard built in Microsoft Excel** to transform raw campaign data into actionable business insights.

The dashboard provides a centralized view of marketing performance across clients, platforms, countries, campaign objectives, devices, and audience segments.

## Key Metrics

* Total Spend
* Revenue
* ROAS
* Impressions
* Clicks
* CTR
* Conversions
* CPA
* Conversion Rate

## Tools & Techniques

* Microsoft Excel
* PivotTables
* Excel Tables
* Advanced Excel Formulas
* KPI Analysis
* Data Cleaning
* Data Visualization
* Interactive Filters
* Marketing Performance Analysis

## Business Use Case

The dashboard is designed to help marketing teams and management quickly identify:

* High- and low-performing campaigns
* Most effective marketing platforms
* Revenue and spending trends
* Campaign efficiency through ROAS and CPA
* Conversion performance
* Client and country-level performance

## Project Objective

To build a reusable **MIS-style marketing analytics solution** that converts raw campaign data into a management-ready dashboard for faster and data-driven decision-making.
